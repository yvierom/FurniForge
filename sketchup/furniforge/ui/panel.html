Set up background generation
  1. Install the FurniForge extension in SketchUp.
  2. Install Node.js and run npm ci --ignore-scripts in the bridge folder.
  3. Install Codex CLI and sign in with your own account.
  4. Run setup-launcher.ps1 from the bridge folder. See the README if you need to provide the path to codex.exe.
  5. Open this workspace and choose GPT Codex. The launcher configures FurniForge MCP for the background session.
  6. Attach images, add an optional description, allow the background session and click Create model.
Automatic launch is currently available for GPT Codex. Claude Code, Cursor and Gemini CLI background integrations are not connected yet.
